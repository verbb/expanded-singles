<h1 align="center">Expanded Singles for Craft CMS</h1>

Expanded Singles is a Craft CMS plugin that brings Craft's Single sections out of a generic sidebar group and puts each one where editors can find it. It is a small change that makes content-heavy control panels noticeably easier to navigate.

List Single sections individually in the Entries sidebar instead of placing them all behind one "Singles" item. Editors can scan the content structure using the names the project already gives those pages.

## Features

- Display each Single section as its own Entries navigation item.
- Use the section titles editors already recognise.
- Open the Single entry itself when an intermediate index adds no value.
- Arrange the items with Craft's existing sidebar customisation.
- Make important one-off pages easier for content teams to locate.
- Choose whether expanded items open the entry or its index.

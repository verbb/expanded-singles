Expanded Singles brings Craft’s Single sections out of a generic sidebar group and puts each one where editors can find it. It is a small change that makes content-heavy control panels noticeably easier to navigate.

List Single sections individually in the Entries sidebar instead of placing them all behind one “Singles” item. Editors can scan the content structure using the names the project already gives those pages.

## Features

- **Expanded sidebar:** Display each Single section as its own Entries navigation item.
- **Clear page names:** Use the section titles editors already recognise.
- **Direct editing:** Open the Single entry itself when an intermediate index adds no value.
- **Native ordering:** Arrange the items with Craft’s existing sidebar customisation.
- **Editor-friendly:** Make important one-off pages easier for content teams to locate.
- **Optional behaviour:** Choose whether expanded items open the entry or its index.
- **Straight to editing:** Optionally send the sidebar item straight to the Single entry’s edit screen rather than its index. Craft’s own sidebar customisation can still be used to arrange the resulting items.

Expanded Singles brings Craft's Single sections out of a generic sidebar group and puts each one where editors can find it. It is a small change that makes content-heavy control panels noticeably easier to navigate.

## Features

- Display each Single section as its own Entries navigation item.
- Use the section titles editors already recognise.
- Arrange the items with Craft's existing sidebar customisation.
- Choose whether each item opens the Single entry directly or its entry index.
